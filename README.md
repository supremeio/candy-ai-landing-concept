# Candy AI landing page concept

A mobile-first landing page concept for **Candy AI**, made for the EverAI Quick Design Challenge.
It is aimed at adults arriving from a Meta ad who have never used an AI companion.

**Theme:** "Your type. Your story."

## What's on the page

- **Hero:** headline with typing chat bubbles, and an arc of AI characters that moves left to right (with a pause button).
- **01 Create your AI girlfriend:** pick a personality (Playful, Thoughtful, Adventurous) and see how she replies.
- **02 Generate videos:** a video preview whose prompt types itself out when you scroll to it.
- **03 Candy Shorts:** a row of real Candy Shorts series titles.
- **Beyond chat:** voice notes and pictures, plus privacy, discreet billing and 18+ notes.
- **One action:** a sticky "Create my AI girlfriend" button that opens the first creation step.

Motion respects `prefers-reduced-motion`.

## Run it

Open `index.html` in a browser, or serve the folder:

```bash
npx serve .
```

It is a single HTML file with no build step. The page is designed for a 402px-wide phone screen and caps at 440px on larger screens.
